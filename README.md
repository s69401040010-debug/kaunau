# ⚡ EnergyMonitor PRO - Home Energy Dashboard

เว็บแอปพลิเคชันหน้าจอแดชบอร์ดสำหรับติดตาม วิเคราะห์ และบริหารจัดการการใช้ไฟฟ้าภายในบ้าน ช่วยค้นหาอุปกรณ์ที่ใช้พลังงานสูง และเสนอคำแนะนำเพื่อการประหยัดค่าไฟฟ้าอย่างมีประสิทธิภาพ

---

## 📌 คุณสมบัติหลัก (Key Features)

* **📊 สรุปภาพรวมการใช้ไฟฟ้า (KPI Overview Cards):**
  * **ค่าไฟประมาณการ:** แสดงค่าไฟประมาณการประจำเดือน พร้อมเปอร์เซ็นต์การเปรียบเทียบกับเดือนก่อนหน้า
  * **หน่วยไฟฟ้ารวม (kWh):** ติดตามปริมาณหน่วยไฟที่ใช้ พร้อมคำนวณค่าเฉลี่ยรายวัน
  * **อุปกรณ์ที่ใช้ไฟสูงสุด:** ระบุตัวการหลักที่ทำให้ค่าไฟแพงทันที
  * **ติดตามเป้าหมายงบประมาณ:** ระบบวัดความก้าวหน้าเทียบกับเป้าหมายที่ตั้งไว้พร้อมหลอด Progress Bar

* **📈 กราฟวิเคราะห์และแสดงผลข้อมูล (Data Visualizations):**
  * **Line Chart:** แสดงประวัติและแนวโน้มการใช้ไฟรายวันย้อนหลังในรอบสัปดาห์
  * **Doughnut Chart:** สัดส่วนการใช้ไฟฟ้าจำแนกตามประเภทเครื่องใช้ไฟฟ้า (แอร์, ตู้เย็น, คอมพิวเตอร์, น้ำอุ่น ฯลฯ)

* **📋 ตารางคำนวณการใช้ไฟรายเครื่อง (Appliance Usage Breakdown Table):**
  * แสดงรายละเอียดกำลังไฟฟ้า (Watts), ระยะเวลาการใช้งานต่อวัน (Hours) และประมาณการค่าไฟต่อเดือนของแต่ละอุปกรณ์

* **💡 ระบบแนะนำการประหยัดไฟอัจฉริยะ (Smart Advice Section):**
  * ให้คำแนะนำเฉพาะบุคคลในการปรับเปลี่ยนพฤติกรรมเพื่อลดค่าไฟ พร้อมประเมินจำนวนเงินที่ประหยัดได้

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5 & JavaScript (ES6+):** โครงสร้างและส่วนประมวลผลหลักของเว็บ
* **Tailwind CSS (via CDN):** สำหรับการออกแบบ UI ที่เป็น Responsive, Modern และสวยงาม
* **Chart.js (via CDN):** ไลบรารีสำหรับวาดกราฟ Interactive ทั้ง Line Chart และ Doughnut Chart
* **Google Fonts (Prompt):** แบบอักษรภาษาไทยที่อ่านง่าย สวยงาม เข้ากับหน้าตาแอปพลิเคชัน

---

## 🚀 วิธีการใช้งาน (Getting Started)

1. บันทึกโค้ด HTML เป็นไฟล์ ชื่อ `index.html`
2. เปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้ (Google Chrome, Safari, Firefox, Edge)
3. ระบบจะแสดงผล แดชบอร์ดติดตามค่าไฟฟ้าทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม
